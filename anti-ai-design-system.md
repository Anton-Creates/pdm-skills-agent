## 1. Запреты в визуале (Visual Blacklist / AI-Slop)

**❌ 1. Purple-to-Blue Gradients (AI Glow / Web3 Tropes)**
- Запрещены градиенты от фиолетового к синему/розовому в hero-секциях, на кнопках и в заголовках.
- Запрещены размытые разноцветные световые пятна (blur orbs / glow meshes) на фоне.
- *Вместо этого:* Строгая монохромная база (черный/белый/серый) + максимум ОДИН функциональный акцентный цвет (индиго, терракота, графит, сланцевый).

**❌ 2. Размытые тени (Overblown Box-Shadows)**
- Запрещены `box-shadow: 0 10px 30px rgba(...)` на каждой карточке. Они создают ощущение дешевого мыла и прячут слабую верстку.
- *Вместо этого:* Четкие структурные границы `1px solid var(--border)`. Прямоугольная швейцарская сетка, плоские поверхности (flat / high-contrast dividers).

**❌ 3. Эмодзи как декор и буллеты**
- Запрещены 🚀, 💡, 🔥, ✨, 🧠, 🎯 в начале списков, на кнопках и внутри плашек.
- *Вместо этого:* Четкие текстовые теги, лейблы (напр. `FinTech`, `Discovery`, `P&L`) или строгие монохромные SVG-иконки (Lucide / Radix / Feather) без цветных кружков-подложек.

**❌ 4. Псевдо-динамические бейджи и кликбейт**
- Запрещены мигающие/пульсирующие зеленые кружки `🟢 LIVE`, `Available for hire`, `⚡ Supercharged by AI`.
- *Вместо этого:* Статичные, честные факты: `Москва · Hybrid / Remote · Открыт к предложениям`.

**❌ 5. Шаблонная триада карточек («Hero → 3 Feature Cards → CTA»)**
- Запрещено генерировать стандартные 3 одинаковые карточки с абстрактным заголовком и тремя строками воды.
- *Вместо этого:* Data-dense интерфейс: таблицы метрик, сравнительные матрицы, таймлайны проектов, фильтруемые сетки кейсов.

**❌ 6. Нечитаемый Glassmorphism**
- Запрещены полупрозрачные фоны с `backdrop-filter: blur()`, сквозь которые плывет текст.
- *Вместо этого:* Контрастные непрозрачные или слегка тонированные поверхности с достаточным коэффициентом читаемости WCAG AAA.

## 2. Типографика и плотность данных (Data-Dense & Editorial)

- **Основной шрифт (Sans-serif):** Отказ от дефолтного `Inter` в пользу характерных гротесков: `Geist`, `Plus Jakarta Sans`, `Cabinet Grotesk` или `Instrument Sans`.
- **Шрифт для цифр и данных (Monospace):** `Geist Mono`, `JetBrains Mono` или `Space Mono` для всех метрик, процентов, дат, тегов и параметров.
- **Иерархия через размер и отступы, а не через цвет:** Заголовки крупные и строгие, тело страницы — 14–16px с выверенным line-height (1.5–1.6).
- **Цифры как главный визуальный якорь:**
  ```
  +10 млн $       -46%           370k+
  Выручка B2B    Time-to-Market   MAU платформы
  ```

## 3. Цветовая система (Строгий монохром)

```css
:root {
  /* Светлая тема */
  --bg-primary: #ffffff;
  --bg-secondary: #f6f8fa;
  --text-primary: #111827;
  --text-muted: #6b7280;
  --border: #e5e7eb;
  --accent: #0f172a; /* Глубокий slate/черный акцент */

  /* Темная тема (Engineering Dark) */
  --dark-bg-primary: #0d1117;
  --dark-bg-secondary: #161b22;
  --dark-text-primary: #f0f6fc;
  --dark-text-muted: #8b949e;
  --dark-border: #30363d;
  --dark-accent: #38bdf8; /* Точечный функциональный акцент */
}
```

## 4. Запрещенные слова в UI-копирайтинге (UI Slop Words)

Если генерируешь текст для кнопок, подсказок, баннеров и заголовков — исключи:
- ❌ *delve, empower, robust, seamless, elevate, revolutionize, game-changer, unlock, unleash, tailored, tapestry, effortless, next-gen.*
- ✅ *Используй точные действия:* «Смотреть метрики», «Архитектура решения», «Открыть кейс», «Код на GitHub», «Скачать PDF».

---

## 5. Чек-лист проверки перед сдачей фронтенда

- [ ] Нет ни одного фиолетово-синего градиента.
- [ ] Все тени либо убраны, либо заменены на границы `1px solid`.
- [ ] В интерфейсе нет эмодзи-декора.
- [ ] Все метрики и цифры набраны моноширинным шрифтом.
- [ ] Кнопки имеют четкие состояния hover/active без избыточных пружинных анимаций.
- [ ] Страница читается на мобильных устройствах без ломающейся сетки.
