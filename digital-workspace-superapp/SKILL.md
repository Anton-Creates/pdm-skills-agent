# Корпоративный суперапп сотрудника (digital-workspace-superapp)

Спроектировать архитектуру и сервисы единого корпоративного супераппа (Цифровой офис сотрудника / ЦОС) для распределенной компании: сквозной доступ к сервисам самообслуживания, бронированию ресурсов, новостям и рабочим инструментам.

## Процесс проектирования

1. **Определи целевую аудиторию и сценарии использования:**
   - Офисные сотрудники, удаленщики, полевой персонал, руководители подразделений.
   - Ключевые пользовательские пути: утренний вход, оформление отпуска/больничного, бронирование переговорки или рабочего места, заказ справки, поиск коллеги в оргструктуре.

2. **Спроектируй каталог микросервисов самообслуживания (Employee Self-Service):**
   - **Кадровые сервисы:** график и согласование отпусков, заказ справок (2-НДФЛ, с места работы), оформление ДМС для себя и семьи, командировки.
   - **Административные сервисы (АХО):** заказ пропусков для гостей, бронирование рабочих столов (Hot-desking) и переговорок, заказ канцтоваров и парковочных мест.
   - **IT-сервисы:** заказ техники и оборудования, подача заявок на доступы, сброс паролей.

3. **Спроектируй контур информирования и вовлечения:**
   - Персонализированная лента новостей по подразделениям и регионам.
   - Виртуальный помощник сотрудника (ИИ-ассистент по внутренним регламентам и базе знаний).
   - Банк идей и опросы удовлетворенности (eNPS, пульс-опросы).

4. **Опиши требования к нефункциональным характеристикам:**
   - Платформы: Web-портал + Мобильное приложение (iOS / Android).
   - Интеграция с корпоративным SSO (Active Directory / Keycloak / SAML).
   - Разграничение прав доступа по ролям и филиалам.

5. **Сформулируй метрики успеха:**
   - Обязательно ответь на 5 вопросов для каждой метрики.

## Формат вывода

```markdown
# Спецификация цифрового офиса сотрудника: [Название компании / Проекта]

## 1. Концепция и архитектура супераппа
- **Целевая аудитория:** [Офис / Удаленка / Филиалы]
- **Форм-фактор:** [Web + Mobile App]
- **Архитектурная модель:** [Микрофронтенды / Витрина мини-аппов]

## 2. Каталог сервисов самообслуживания
| Сервис | Категория | Сквозной процесс | Время выполнения (SLA) |
| :--- | :--- | :--- | :--- |
| Заказ справки 2-НДФЛ | Кадры | Заявка -> 1С:ЗУП -> Электронный документ | До 1 рабочего дня |
| Бронирование стола | АХО | Выбор на интерактивной карте -> QR-код | Мгновенно |
| Оформление отпуска | Кадры | Выбор дат -> Согласование лида -> Приказ | До 2 рабочих дней |

## 3. Информационный контур и вовлечение
- **Лента новостей:** таргетинг по городам и департаментам.
- **ИИ-ассистент:** ответы на вопросы по ДМС, отпускам и графикам выплат.
- **Опросы:** ежемесячный пульс-опрос команды в 2 клика.

## 4. Метрики эффективности
- **DAU / MAU сотрудников:** регулярность использования цифрового офиса.
- **Self-Service Adoption Rate:** доля заявок, оформленных без прямого обращения к кадровикам/секретарям.
- **Time-to-Resolve:** среднее время от подачи заявки до получения результата.
- **eNPS сотрудников:** индекс удовлетворенности внутренними сервисами.
```

## Правила

- Опирайся на реальные сценарии работы сотрудников, а не на абстрактные функции.
- Не используй длинные тире. Заменяй их на двоеточия, точки или стандартные дефисы.
- Каждая предложенная метрика должна пройти проверку по правилу 5 вопросов:
  1. Кто владеет метрикой?
  2. Как часто смотрим?
  3. Какие события ее считают?
  4. Какой порог решения?
  5. Как ее можно испортить или накрутить?
