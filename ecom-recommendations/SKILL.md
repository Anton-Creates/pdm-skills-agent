# Товарные рекомендации и Total Look в E-com (ecom-recommendations)

Спроектировать систему товарных рекомендаций для интернет-магазина: Cross-Sell блоки в карточке товара, стилистические комплекты «Собери образ» (Total Look), персонализация главной страницы и допродажи в корзине.

## Процесс проектирования

1. **Определи сценарии и точки размещения рекомендаций:**
   - **Карточка товара (PDP):** блок «С этим товаром сочетается / Собери образ», блок «Похожие товары (Альтернативы)».
   - **Корзина (Cart Drawer / Checkout):** импульсные допродажи (аксессуары, сопутствующие товары, товары до бесплатной доставки).
   - **Главная страница:** «Вы недавно смотрели», «Рекомендовано вам на основе истории покупок», «Тренды вашей любимой категории».

2. **Спроектируй механику «Собери образ» (Total Look / Shop the Look):**
   - Интерактивное фото модели с кликабельными точками (Hotspots) на элементах одежды и аксессуарах.
   - Быстрый выбор размеров для всего комплекта и кнопка «Купить весь образ со скидкой 10%».
   - Автоматическая замена отсутствующих размеров на ближайшие стилистические аналоги.

3. **Спроектируй логику подбора и ранжирования (Recommendation Logic):**
   - Коллаборативная фильтрация (Collaborative Filtering): «Покупатели этого товара также купили X».
   - Контентная фильтрация (Content-based): совпадение бренда, ценового сегмента, цветовой палитры и стиля.
   - Бизнес-правила (Guardrails): исключение из рекомендаций уже купленных товаров, товаров без остатка и несезонных позиций.

4. **Спроектируй интерфейс и микроанимации:**
   - Горизонтальный свайпер карточек с сохранением позиции.
   - Индикация выгоды при покупке комплектом (Bundle Discount).

5. **Сформулируй метрики влияния рекомендаций на выручку:**
   - Обязательно ответь на 5 вопросов для каждой метрики.

## Формат вывода

```markdown
# Спецификация товарных рекомендаций: [Название проекта]

## 1. Сетка рекомендательных блоков
| Расположение | Название блока | Алгоритм подбора | Бизнес-цель |
| :--- | :--- | :--- | :--- |
| Карточка (PDP) | Собери образ (Total Look) | Стилистический сет стилиста / AI-матчинг | Рост глубины чека (Items per Order) |
| Карточка (PDP) | Похожие товары | Близость по вектору эмбеддингов описаний | Удержание при отсутствии размера |
| Корзина (Cart) | Добавьте до бесплатной доставки | Сопутствующие товары до 1500 руб. | Повышение среднего чека (AOV) |

## 2. Механика «Собери образ» (Shop the Look)
- **Визуализация:** лукбук с интерактивными точками (пинами) на обуви, брюках, пиджаке.
- **Действие:** выбор размеров в выпадающем списке прямо внутри модального окна.
- **Оффер:** «Купите образ целиком за 18 900 руб. вместо 21 000 руб.».

## 3. Бизнес-ограничения (Guardrails)
- Не рекомендовать мужскую обувь пользователям с чисто женской историей покупок.
- Не показывать товары с нулевым остатком на складе региона пользователя.

## 4. Метрики эффективности
- **Recommendation CTR:** кликабельность рекомендательных блоков.
- **Recommendation Revenue Share:** доля выручки интернет-магазина, сгенерированная кликами по рекомендациям.
- **Average Order Value (AOV) Lift:** прирост среднего чека для заказов с товарами из рекомендаций.
- **Items per Order (Глубина чека):** среднее количество позиций в одном заказе.
```

## Правила

- Рекомендации должны учитывать локальный остаток на складе пользователя, чтобы не предлагать товары с долгой доставкой.
- Не используй длинные тире. Заменяй их на двоеточия, точки или дефисы.
- Каждая метрика должна пройти валидацию по правилу 5 вопросов.
