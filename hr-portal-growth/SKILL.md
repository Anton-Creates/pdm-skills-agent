# HR-портал развития и талантов (hr-portal-growth)

Спроектировать платформу развития сотрудников: сквозной онбординг новичков, индивидуальные планы развития (ИПР), матрицы компетенций и грейдов, циклы Performance Review и оценку 360.

## Процесс проектирования

1. **Спроектируй сценарий онбординга и адаптации (Welcome Track):**
   - Интерактивный план адаптации на первые 30, 60 и 90 дней.
   - Чек-листы для новичка и бадди/наставника: знакомство с командой, настройка доступов, первые рабочие задачи.
   - Промежуточные пульс-опросы удовлетворенности адаптацией на 1-й, 2-й и 3-й месяц.

2. **Опиши модель профессионального роста (ИПР и грейды):**
   - Матрица компетенций: Hard Skills и Soft Skills по грейдам (Junior -> Middle -> Senior -> Lead).
   - Конструктор ИПР (Индивидуальный план развития): формулировка целей по SMART, привязка к курсам, книгам и проектам компании.
   - Менторство и трекинг прогресса регулярными 1-on-1 встречами.

3. **Спроектируй процесс регулярной оценки (Performance Review и 360):**
   - Настройка цикла оценки: самооценка (Self-review), оценка коллег (Peer-review), оценка руководителя.
   - Калибровочные сессии для выравнивания оценок между командами.
   - Формирование отчета с дельтами развития и обновлением грейда / компенсации.

4. **Опиши внутреннюю мобильность (Internal Mobility):**
   - Витрина внутренних вакансий компании.
   - Автоматический матчинг профиля сотрудника с требованиями открытых позиций.
   - Прозрачный протокол согласования перехода между подразделениями.

5. **Определи метрики эффективности:**
   - Обязательно ответь на 5 вопросов для каждой метрики.

## Формат вывода

```markdown
# Спецификация HR-портала развития: [Название компании / Проекта]

## 1. Сценарий адаптации (Онбординг 30-60-90)
- **Первая неделя:** базовые чек-листы, знакомство с бадди, доступы.
- **30 дней:** выполнение первой учебной/боевой задачи, срез по адаптации.
- **90 дней:** защита итогов испытательного срока и постановка первого ИПР.

## 2. Модель развития и ИПР
- **Матрица навыков:** требования к грейдам с примерами артефактов.
- **Структура ИПР:** 3 ключевые развивающие цели, ссылки на материалы, дедлайны.
- **Синхронизация:** фиксация договоренностей на встречах 1-on-1 раз в 2 недели.

## 3. Протокол Performance Review (Оценка 360)
| Этап | Участники | Срок | Результат |
| :--- | :--- | :--- | :--- |
| Выбор респондентов | Сотрудник + Тимлид | 3 дня | Список из 3-5 коллег для оценки |
| Заполнение анкет | Коллеги, Лид, Сотрудник | 7 дней | Сводный профиль компетенций |
| Калибровка | Руководители направлений | 2 дня | Итоговые оценки и пересмотр грейдов |
| Фидбек 1-on-1 | Тимлид + Сотрудник | 5 дней | Обновленный ИПР на следующий цикл |

## 4. Метрики эффективности
- **Retention на испытательном сроке:** доля новичков, успешно прошедших 90 дней.
- **eNPS сотрудников:** готовность рекомендовать компанию как место работы.
- **% выполнения ИПР:** доля сотрудников, закрывших поставленные развивающие цели.
- **Review Cycle Duration:** время от старта сбора анкет до проведения фидбек-встречи.
```

## Правила

- Без общих фраз. Описывай конкретные шаги, дедлайны и артефакты.
- Не используй длинные тире. Заменяй их на двоеточия, точки или стандартные дефисы.
- Каждая предложенная метрика должна пройти проверку по правилу 5 вопросов.
