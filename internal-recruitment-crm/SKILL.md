# Внутренняя HR CRM и ATS для рекрутмента (internal-recruitment-crm)

Спроектировать внутреннюю систему управления подбором персонала (Applicant Tracking System / HR CRM): воронка кандидатов, кабинет нанимающего менеджера, согласование офферов и аналитика найма.

## Процесс проектирования

1. **Спроектируй воронку подбора персонала (Hiring Pipeline):**
   - Этапы: Заявка на подбор -> Скрининг резюме -> Первичное интервью HR -> Техническое интервью -> Финал с лидером -> Согласование оффера -> Оффер принят.
   - База кандидатов (Talent Pool) с тегами навыков, историей взаимодействий и защитой персональных данных (152-ФЗ).
   - Интеграция с карьерными сайтами (HeadHunter, Habr Карьера) и Telegram-ботами для откликов.

2. **Спроектируй кабинет нанимающего менеджера (Hiring Manager Portal):**
   - Подача заявки на открытие вакансии: профиль роли, грейд, бюджетная вилка, сроки.
   - Скоринг кандидатов: единая шкала оценки после собеседований и шаблоны фидбека (Scorecards).
   - Согласование условий оффера (грейд, оклад, бонусы) в один клик.

3. **Спроектируй автоматизацию коммуникаций с кандидатами:**
   - Шаблоны писем и сообщений для каждого этапа воронки.
   - Автоматический сбор свободных слотов для интервью через интеграцию с корпоративным календарем.
   - Автоматическая отправка вежливых отказов с персонализацией.

4. **Опиши сквозную аналитику найма:**
   - Воронка конверсий по источникам кандидатов (Direct, Referral, Агентства).
   - Скорость прохождения кандидатов по этапам (Time in Stage).
   - Аналитика причин отказов кандидатов и компании.

5. **Сформулируй метрики эффективности найма:**
   - Обязательно ответь на 5 вопросов для каждой метрики.

## Формат вывода

```markdown
# Спецификация внутренней HR CRM / ATS: [Название компании / Проекта]

## 1. Структура воронки найма
- **Этапы воронки:** Заявка -> Скрининг -> HR-интервью -> Тех-интервью -> Оффер -> Выход.
- **Scorecards:** единая форма оценки компетенций (Hard/Soft) после каждого этапа.

## 2. Кабинет нанимающего менеджера
- **Заявка на роль:** утверждение штатной единицы и согласование зарплатной вилки.
- **Календарь собеседований:** авто-выбор свободных слотов в календаре лида.

## 3. Автоматизации и интеграции
- **Источники резюме:** автоматический импорт откликов с HH / Хабр / Telegram.
- **КЭДО и онбординг:** бесшовная передача данных принятого кандидата в корпоративный суперапп.

## 4. Метрики эффективности рекрутмента
- **Time-to-Hire:** среднее количество дней от открытия вакансии до принятия оффера.
- **Cost-per-Hire:** полная стоимость закрытия одной вакансии.
- **Offer Acceptance Rate:** процент выставленных офферов, принятых кандидатами.
- **Качество найма (Quality of Hire):** % кандидатов, успешно прошедших испытательный срок.
```

## Правила

- Фокусируйся на скорости закрытия позиций и удобстве нанимающих менеджеров.
- Не используй длинные тире. Заменяй их на двоеточия, точки или дефисы.
- Каждая предложенная метрика должна пройти валидацию по правилу 5 вопросов.
