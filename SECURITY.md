# Security Policy

## Supported Versions

We actively maintain the latest version of `pdm-skills-agent` with prompt defense standards and prompt-injection mitigations.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability or prompt-injection vector within any of the 130 PM framework skills, please report it via [GitHub private vulnerability reporting](https://github.com/Anton-Creates/pdm-skills-agent/security/advisories/new).

Please include:
- The specific skill name (e.g., `prd`, `prioritize`, `competitor-scan`)
- Steps to reproduce or the adversarial prompt payload
- Expected vs observed model behavior

We will review reports within 48 hours and release patched skill definitions.
