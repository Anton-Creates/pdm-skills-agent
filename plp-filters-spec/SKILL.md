# Листинг товаров и фильтрация в E-com (plp-filters-spec)

Спроектировать каталог товаров и страницу листинга (Product Listing Page / PLP): многоуровневая фасетная фильтрация, умные сортировки, карточки в сетке, быстрый просмотр (Quick View) и управление пагинацией.

## Процесс проектирования

1. **Спроектируй фасетные фильтры (Faceted Filtering):**
   - Категорийные атрибуты: бренды, ценовой диапазон (слайдер + ручной ввод), размеры, цвета, материалы, сезон, страна производства.
   - Экспресс-фильтры (чипсы сверху): «Доставка сегодня/завтра», «Со скидкой», «Хиты продаж», «Премиум».
   - Мгновенный пересчет количества подходящих товаров при выборе чекбокса (без перезагрузки страницы).

2. **Спроектируй правила сортировки (Sort Order):**
   - По популярности (алгоритмический скоринг кликов и покупок), по размеру скидки, по возрастанию/убыванию цены, по новинкам, по пользовательскому рейтингу.

3. **Спроектируй миникарточку товара в сетке (Grid Product Card):**
   - Фото с возможностью листать ракурсы при наведении (Hover Carousel).
   - Быстрый выбор размера и добавление в корзину в 1 клик.
   - Кнопка добавления в избранное (сердечко) с анимацией.
   - Бейджи: «Новинка», «Скидка -40%», «Экспресс», «Бестселлер».

4. **Спроектируй навигацию и пагинацию:**
   - Бесконечный скролл (Infinite Scroll) с кнопкой «Показать еще» каждые 3 экрана для сохранения ориентации пользователя и доступа к футеру.
   - Сохранение позиции скролла и выбранных фильтров в URL (глубокие ссылки / Deep Linking).

5. **Сформулируй метрики эффективности листинга:**
   - Обязательно ответь на 5 вопросов для каждой метрики.

## Формат вывода

```markdown
# Спецификация листинга и фильтрации (PLP): [Категория]

## 1. Фасетная панель фильтров
- **Структура:** Боковая панель на десктопе, выдвижная шторка (Bottom Sheet) на мобильных.
- **Логика применения:** Мультивыбор с кнопкой «Показать [N] товаров» внизу шторки.
- **Чипсы быстрого доступа:** «Доставка завтра», «Только со скидкой», «Бренды A-Z».

## 2. Модель сортировки
| Тип сортировки | Формула ранжирования | Приоритет применения |
| :--- | :--- | :--- |
| По популярности | Продажи за 14 дней * 0.5 + Просмотры * 0.3 + Наличие * 0.2 | По умолчанию |
| По скидке | Величина скидки в % от базовой цены | Ручной выбор |
| По новинкам | Дата поступления на склад (последние 30 дней) | Ручной выбор |

## 3. Функционал карточки в каталоге
- **Hover Preview:** переключение до 4 фото без перехода в карточку.
- **Quick Add:** выпадающий список размеров при нажатии на «В корзину».
- **Индикаторы остатка:** «Остался 1 размер» для создания срочности (FOMO).

## 4. Метрики эффективности листинга
- **PLP-to-PDP Click-Through Rate (CTR):** доля пользователей каталога, перешедших в карточку товара.
- **Filter Usage Rate:** % пользователей, применивших хотя бы один фильтр или сортировку.
- **Quick-Add Conversion:** доля добавлений в корзину напрямую из листинга без захода в карточку.
- **Zero-Results Rate:** % поисковых/фильтровых запросов, вернувших 0 товаров.
```

## Правила

- Избегай пустых выдач (Zero Search Results). Предлагай автоматическое расширение фильтров или похожие товары.
- Не используй длинные тире. Заменяй их на двоеточия, точки или дефисы.
- Каждая метрика должна пройти валидацию по правилу 5 вопросов.
